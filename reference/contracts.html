Contracts

Contracts are the interfaces of the framework's services, in Omnitrix\Contracts. Type your own code against them instead of the concrete classes: it stays independent of the implementation, and tests can pass simple doubles. Every worker container holds the configured service under its contract name.

use Omnitrix\Contracts\Mailer;

final class InvoiceService
{
    public function __construct(private readonly Mailer $mailer) {}

    public function remind(Invoice $invoice): void
    {
        $this->mailer->send(new InvoiceReminder($invoice), $invoice->email);
    }
}

// in a handler: new InvoiceService(Facade::container()->get(Mailer::class))

Contracts follow the versioning policy: changing one is a breaking change, listed in the upgrade notes.
